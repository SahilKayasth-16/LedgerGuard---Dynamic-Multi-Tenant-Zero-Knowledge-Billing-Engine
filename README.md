# LedgerGuard

Dynamic multi-tenant billing engine focused on tenant isolation, idempotent transactions, and secure API access.

## Tech Stack

* **Backend:** Node.js, Express, TypeScript
* **Database:** MongoDB, Mongoose
* **Cache/Locks:** Redis
* **Authentication:** JWT with RS256
* **Frontend:** React, Vite, TypeScript, Tailwind CSS, Chart.js

## Core Features

* Multi-tenant database isolation
* Dynamic MongoDB connections
* Idempotent billing ledger
* Redis distributed locks
* MongoDB transactions
* Usage analytics dashboard
* RS256 JWT authentication

## Project Structure

```text
LedgerGuard/
├── client/    # React frontend
└── server/    # Express + TypeScript backend
```
